# Carousel's own assets

`key-cream.png`, `key-gold.png`, `key-ink.png`, `key-orange.png` are reused from oncarousel.com
(`/assets/img/v2/`) so the keycap component matches Carousel's design system exactly.
The icons, labels and press behaviour on top of them are this project's code, with
values read from Carousel's live `#checks-keys`.

Everything else in this hero is generated or written for this exercise: the character
and all her gaze frames (Seedream 5.0 Pro), the floating props (GPT Image 2.5), the copy.

Also reused from oncarousel.com, unchanged: the wordmark (`carousel-horizontal.svg`), favicon and
apple-touch icon, and the customer logos that appear in Carousel's own ticker (`capital-lynk-logo.png`,
`canacap-wordmark.png`, `unity-logo.png`). Holand Leasing, Sutton, Forward Funding and BH Holdings are set
as text, exactly as Carousel sets them.
