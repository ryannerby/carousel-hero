(`/assets/img/v2/`) so the keycap component matches your design system exactly.

and all her gaze frames (Seedream 5.0 Pro), the floating props (GPT Image 2.5), the copy.

apple-touch icon, and the customer logos that appear in your ticker (`capital-lynk-logo.png`,
`canacap-wordmark.png`, `unity-logo.png`). Holand Leasing, Sutton, Forward Funding and BH Holdings are set
as text, exactly as you set them.
